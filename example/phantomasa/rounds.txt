; Phantomasa rounds. Edit, then rebuild (build.sh).
; Everything after ';' is a comment. Coordinates are in CHARACTERS, like
; the original BASIC: Y = row 0-23, X = column 0-31.
;
;   round <stage> <number> screen=<name in gfx/screens, without NN->
;     start=<W>,<A>        player's feet row W and left column A (he is
;                          2x2 characters: rows W-1..W, columns A..A+1)
;     exit=<W>,<A>         the round ends when he stands with his feet on
;                          row W and his left column at A; W=* = any row
;     snot=<first>,<speed> stage 3: the snot starts at row <first> (may be
;                          negative: it takes a while to appear) and comes
;                          down one row every <speed>+1 ticks
;   box <Y>,<X> ...        pushable boxes (2x2), top-left corner. These are
;                          the only boxes: red graphics in the pictures are
;                          solid scenery. All the
;                          boxes of a round must have Y of the same parity
;                          (the first box decides): you can only push a box
;                          when your rows are its rows, and that test is
;                          what keeps stacked boxes whole (stage 1 uses
;                          even rows, stage 3 odd rows)
;   portal <Y>,<X>         the flashing portal (2x1, decoration + floor)
;   platform <Y>,<X> <min>,<max> <dir>
;                          moving platform (2x1) at row Y, starting at
;                          column X, bouncing between columns min and max,
;                          dir = 1 right, -1 left
;   gate                   round 9 of stage 1: the barrier at column 12,
;                          rows 0-5, opens when the player reaches it
;   door <Y>               stage 3: opens the way out through the right wall
;                          on rows Y and Y+1 (cols 22-31)
;   tiles <Y>,<X> <attr> <text>
;                          font characters painted on the background, solid
;                          unless their attribute is 7 (e.g. "lmn" pieces of
;                          platform). attr in decimal or $hex.
;
; Free space is attribute 7 (white ink on black paper) in the screen PNGs;
; attribute 1 (blue ink on black) kills when you stand on it; anything
; else is solid. See README.md.
