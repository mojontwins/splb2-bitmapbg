# The six games of the compilation. tools/conv.py reads this file.
#
#   game NAME                     starts a game (until "end")
#     menu "TEXT"                 its line in the menu and the HUD (22 max)
#     title "TEXT"                its full title (32 max)
#     ink N                       the player's colour (0-7)
#     lives N                     lives (pheng: 5)
#     start ROOM X Y              where it starts (pixels: x 0-240, y 0-160)
#     ending "TEXT"               typed when you reach the goal
#     room ROOM L R U D [fly]     a room of gfx/rooms.txt and its exits
#                                 (rooms of this game, - none). A room
#                                 left without an exit is a wall; falling
#                                 off the bottom without one kills. fly:
#                                 the player flies there (4 directions).
#       TYPE X1 Y1 X2 Y2 SPEED FIGURE INK
#                                 up to 4 enemies (src/enemies.h explains
#                                 each TYPE): linear chaser random drop
#                                 ghost bouncer hopper platform goal faller
#                                 item. FIGURE: a name of gfx/sprites.txt.
#                                 INK: 0-7 (+64 BRIGHT). Pixels: the
#                                 figure's top-left corner; standing on
#                                 row R means Y = R * 8 - 16.
#       toggle X1 Y1 X2 Y2 SPEED TILE ATTR
#                                 cells (characters) switching on and off
#                                 every SPEED * 8 frames: TILE in ATTR,
#                                 deadly, or nothing.
#   end
