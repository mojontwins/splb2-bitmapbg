# Every text of the game. tools/conv.py turns this into src/assets.h.
#
#   @name        starts a text; the game uses it as t_name
#   the lines that follow are the text. A line break here is a line break
#   on screen; texts typed with the typewriter effect are also word-wrapped
#   at 32 columns, so a paragraph can be one long line.
#   A line ending in \ continues on the next line without a line break.
#   Lines starting with # are comments. Blank lines are ignored inside a
#   text (write {nl} for an empty line on screen).
#
# Characters: plain ASCII as the Spectrum ROM draws it (^ is the arrow,
# ` is the pound sign), © ↑ and the Spanish á é í ó ú ñ ¡ ¿.
# {A} .. {U} are the UDGs (gfx/tiles.png, characters 144-164), {nl} a line
# break, and the Unicode quarter blocks ▘▝▀▖▌▞▛▗▚▐▜▄▙▟█ are the Spectrum's
# block graphics (characters 128-143).
#
# The wording is the original's, spelling included. Only the 1990 tricks
# for missing characters became the real thing: "tu"+CHR$ 8+"'" is "tú",
# "a|o" is "año", "[" was "¡" and "]" was "¿". The hand-made line breaks
# (runs of spaces, words split with "-") are gone: the typewriter wraps.
